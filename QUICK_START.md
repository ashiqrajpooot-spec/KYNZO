# ASH MART - Quick Start Guide

## 🚀 Launch Your Store

### Step 1: View Homepage
```
http://localhost:3000/
```
Explore featured products, categories, and deals.

### Step 2: Try Advanced Search
```
http://localhost:3000/search
```
- Search for products
- Filter by price, category, rating
- Sort by relevance, price, rating, reviews
- Toggle grid/list view

### Step 3: Search with Query
```
http://localhost:3000/search?q=wireless
```
Pre-filled search results for "wireless" products.

### Step 4: View Product Details
```
http://localhost:3000/product/1
```
See full product information, ratings, seller info, related products.

### Step 5: Admin Access

## 🆘 Troubleshooting

### Search Not Working
- Check internet connection
- Clear browser cache
- Try a different search term

### Product Links Not Working
- Ensure product ID exists
- Check network tab
- Clear browser cache

### Seller Approval Issues
- Check email for updates
- Verify all fields completed
- Contact support

### Admin Login Issues
- Verify credentials
- Check caps lock
- Clear browser data
